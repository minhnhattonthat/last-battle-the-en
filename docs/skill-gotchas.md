# Skill gotchas (one line each: reference file it belongs in, then the fact)

- translation.md §Review / SKILL.md ground rules: in an Orca run the `codex exec` fallback can be out of quota ("You've hit your usage limit"); check it with a one-line prompt before planning on it. The context-mode hook stubs Bash output and Reads over ~4 KB, so batch files must be read with `limit` (60-75 rows) and probes must print little.
- translation.md §Batch design / assets/batches.py: slot-based inserters with a far-jump relocation can't grow slots shorter than the jump (here 5 bytes: 2-tile menu words); the batch check needs that rule, or `build.py` fails after the merge.

- graphics.md §Survey / platform-snes.md: a game can keep a second copy of its font in another compression format for one mode (here battle: its own LZ and load list), so patching the field font block changes nothing there; find it by the VRAM DMA source (`snes_dmalog.lua`) and the writers of that WRAM buffer, not by `decomp_src`-style LZ logs.
- SKILL.md Step 0 / guard hook: in a fresh Orca worker session the plugin's guard did not block the canary; adding the `hooks` block with `python "$HOME/.claude/plugins/marketplaces/..."` worked (a `~` path inside quotes is not expanded and fails).
- emulator-qa.md: `emu.py --state-in` replays without the route/mash that made the state; a probe expecting the same events must pass the same `--mash` too (a WRAM dump without it showed the map never loaded).
- platform-snes.md / pipeline.md §Recon: `dis65816.py` is linear only; a flow-following walk that lists every access to the script pointer along all paths (this repo's `tools/re_flow.py`) gave each control code's argument layout, including byte-sized args and indirect sub-tables, in one pass. Candidate for the skill.
- pipeline.md §Recon (font ID): for a JIS-ordered kanji subset, a monotonic DP against rendered MS Gothic plus an eye proof (glyph over mapped char, 4-row strips: denser sheets were misread) found 42 aligner errors in 1066; checking the result is strictly JIS-increasing caught one off-by-one correction.
- SKILL.md / context-mode: Bash output over ~4 KB is replaced by an index stub; print compact summaries or Read files with offset/limit.
- emulator-qa.md §Visual QA (Orca workers): `codex exec -i a.png b.png "prompt"` takes the prompt as one more image (`-i` is variadic); pipe the prompt on stdin instead. A worker's codex fallback can also fail on the account's usage limit: check the log before relying on it.
- graphics.md §Survey: a whole-ROM LZ header-signature scan (u16 L, u16 L-2) matches inside raw graphics too; dedupe overlaps and cap the decompressed size before rendering, or the sweep is mostly stripes.
- emulator-qa.md: two runs of the same ROM with the same route and `--mash` are not frame-identical in MesenCE (animation/typing phase), so a trap-ROM check by pixel diff needs a same-session baseline and a by-eye compare; a read-watch Lua probe on the trapped ranges (`trap_reads.lua`) is the reliable signal.
- SKILL.md ground rules (TSV): the Edit tool drops a tab at the very end of old/new_string, so an edit ending in "name<TAB>" glued two columns of scenes.tsv; never end an edit string with a tab, and have the loader assert the column count (run_scenes.py does).
- emulator-qa.md §Debug tool: for a script-VM game, a warp that rewrites the game's own map-change request at the loader's first call, plus running injected script bytes from free WRAM through the field loop's per-frame script hook, reached rooms, shops, inns and forced battles with no position or flag knowledge; replacing the room's entry script instead skipped its fade-in (black screen).
- emulator-qa.md §Debug tool (GOD): refilling HP at frame end does not stop a one-hit kill inside the frame; give the battle copies a huge HP/max instead, and find the battle's own unit copies (here `$1298 + i*$28`), not just the field records.
- emulator-qa.md §emu.py: `--var MASH=..` is rejected as a driver global; use `--mash N`. A warp script can queue its own presses with `L.press` from `L.on_frame` (boot + name entry without a route file).
- graphics.md §Survey (SNES): a whole-ROM static sweep at 1x in 2bpp/4bpp was illegible for most raw regions, and its LZ-block sheets were mostly tilemaps; render each raw region as snes8 too (this game's 0x30000 pictures are 8bpp) and treat per-screen VRAM dumps as the real survey.
- emulator-qa.md §Debug tool (saves): the save point was not in any script text: the save menu hung off an overworld-only menu icon. Finding the SRAM service's callers (`JSL` to the routine that reads the slot signature) and walking up to their menu jump table found it in minutes; check every menu (field AND overworld/world map) icon by icon before hunting text.
- emulator-qa.md §emu.py (Mesen): battery SRAM starts random in Mesen, so a no-save run's .srm differs every run and diffing SRAM between runs is noise; diff only the slot the game wrote, and compare WRAM instead.
- emulator-qa.md §Hooks (Mesen): `emu.setState(s)` with `s["cpu.pc"]` changed inside an `L.on_exec` hook skips code (here an endless wait on the sound CPU before the staff roll); skipping a sound-port poll mid-protocol instead hung the next SPC upload, so skip the whole call that owns the wait.
- emulator-qa.md §Debug tool (save editor): the save stream was a descriptor table (gather list, plain copies, 1-bit flags, per-field bit widths); decoding the table and its 4 handlers from the ROM gave an exact round-trip in one pass, including the packer's padding bits (ROLs through a carry left set by the loop's last CMP).
- pipeline.md §Identity (LZ): the original compressor's parse was not greedy (literal run after literal run), so an own compressor can't be byte-exact; the build keeps each unchanged block's original stream (identity holds), and a second test recompresses and moves every block, then decodes every pointer slot. Run the debug-scene tour on that relocated build too.
- emulator-qa.md §Debug tool (comparing runs): warp scene runs are not frame-deterministic (two runs of one ROM differed in 20 of 113 final frames: battle animation phase, SRAM noise), and a build whose LZ streams differ shifts decompression timing and so the RNG (different random encounters on mash-A routes); compare scene-by-scene by eye, not by exact pixels.
- emulator-qa.md (Windows): PowerShell variables are case-insensitive: a skill-path variable `$S` was clobbered by a loop variable `$s`, so `sheet.py` ran from the wrong dir. Use distinct names.
- platform-snes.md §Engine patching: a script VM reading through a 24-bit pointer can run text straight from ROM; one free control high byte as a far jump (word + 24-bit address) relocates strings without moving any block address or pointer (this repo's `docs/re/vwf.md`).
- `references/emulator-qa.md`: many `--qa ID=TEXT` args built in Python and read back with `mapfile` in Git Bash carry a trailing CR (Python text mode writes CRLF on Windows) and argparse rejects them; call `build.py` from Python with `subprocess.run([...])` instead.
- `references/translation.md` / `assets/batches.py`: dialogue with a speaker-name line (`Name{nl}"speech`, the JP 名前{nl}「 form) turned wrapping off for the whole page (any {nl} = manual breaks) and the entry-level quote flag never indented speech after a name; wrap the speech after the name line, decide speech/narration per page from the JP page, and give $C000+ control words zero width (`tools/batches.py` wrap/px, session 14).
