# Text engine, encoding, font

Dump: `rom.sha1`. LoROM, 2 MB (header `$7FC0`: "THE LASTBATTLE", map $20, type $02, size $0B, SRAM $03 = 8 KB, battery).
No earlier fan translation found (web search 2026-11-23; Giant Bomb lists none).

## Encoding (verified)
- Script = stream of **16-bit little-endian words**, read by the VM loop at `01:B79F` (`LDA [$10]; INC $10 x2`).
  Script pointer: DP `$0C00` + `$10` (24-bit, so WRAM `$7E0C10-$7E0C12`).
- Word `< $0300`: tile code, `ORA #$2000` and written straight to the BG3 tilemap buffer (`01:B7D1`). Window parts etc.
- Word `$0300-$7FFF`: glyph `code - $0300` drawn into the bitmap text box (`01:B81F` -> `01:B882`).
- Word `>= $8000`: control code; high byte looked up in the 56-byte table at `01:BAB5`, handler pointers at `01:BAED`
  (`01:BA96`). Low byte = argument. Several handlers read further words; see Control codes.
- verified by: decoding the name-entry prompt at file `0x023938` ("　この世界で使う{nl}真の名前を入力して下さい。{end}")
  word by word against the screen (`work/qa/ppu1`, frame 1150 of `tools/routes/boot.txt`), and by logging the
  glyph reads per frame (`tools/lua/romreads_addr.lua`).

## Font (verified)
- 16x16 1bpp, 32 bytes per glyph as four 8x8 1bpp tiles in order TL, TR, BL, BR. Drawn at a 12 px advance into a
  2bpp bitmap canvas on BG3 (tiles `$E0+`, map `$D800` byte addr, chr `$C000`): `01:B8F5`/`01:B8FB` jump tables
  handle the even/odd half-tile phase.
- Base pointer at `$1A:8015` = linear `$1DFCF3` -> **file 0x107CF3**; glyph address = base + (code - $0300) * 32.
- 1233 glyphs (to file 0x111713) -> codes `$0300-$07D0`. Render any range: `python -X utf8 tools/re_glyphs.py OUT.png --range 300 380 --rowfmt tltr`.
- Order: a **JIS X 0208-ordered subset** (only the characters the game uses):
  `$0300` space, `$0301-$030F` symbols (。・？！ヶ／～「『』＋－, `$030D` an odd glyph, ＊ ⇒), `$0310-$0319` ０-９,
  `$031A-$0333` Ａ-Ｚ (no lowercase seen yet), `$0334-$0383` hiragana without ゎゐゑ (を = `$0382`, ん = `$0383`),
  then katakana (not yet checked) and kanji in JIS order (界 `$0432` < 使 `$0535` < 真 `$05C2` < 世 `$05D2` < 前 `$0602` < 入 `$06B5` < 名 `$0748`).
- `$0384-$03D5` katakana (no ヮヰヱ), `$03D6-$07AD` JIS level-1 kanji subset (愛 ... 腕), `$07AE-$07D0` 35 extra
  kanji out of order, staff names for the credits (裔居孝岡本郎哲...; 本 repeats `$0736`).
- verified by: `tools/re_kanji_align.py` (monotonic DP against MS Gothic / Yu Gothic renders of JIS X 0208) then
  every cell proofed by eye on `tools/re_tbl_sheet.py` sheets; 42 aligner errors corrected in
  `tools/re_kanji_fix.py`, which writes `tbl/font_jp.tsv`; the result is strictly JIS-increasing (a test).
  `tbl/jp.tbl` (generated by `tools/gen_jp_tbl.py`) covers every glyph.
- Fixed-width 12 px cells in a 16 px glyph: English needs a VWF or a narrow font (phase 5 engine spike).

## Control codes (verified: every room block walks with no desync, `tests/test_script_dis.py`)
High bytes in the table at `01:BAB5` (handlers `01:BAED`): A0 A1 A3 A4 A5 B0-BE C0 C1 C2 D0-D8 E0 E1 E2 E4 E5 E6
E8-EF F4 F5 F6 F8 F9 FA FB FC FE FF. Any other high byte hangs the dispatcher. A handler returning non-zero ends
the VM loop (`01:B7BC`). **Argument bytes follow the word and can be odd in number: the stream is not
word-aligned.** Layouts (b = byte, w = word, J = jump target word, an address in the block image) from the handlers
(`tools/re_flow.py ENTRY` lists every script-pointer access along all paths), coded in `tools/script_dis.py`:
| Op | Args | Meaning (provisional) |
|---|---|---|
| A0 / A1 | b / w b | chest: item / money? (skipped if flag lo set; runs bank-04 scripts `$04B64E/50/52`) |
| A4 | - | lo < $80: sub-table `01:BB80`; lo >= $80: print bank-04 text from pointer table `$04:B2FC` |
| B4, B5 | w | |
| B6 | w (none if lo = FF) | |
| B7, B8 | w b if lo = 0, else none | |
| BA | w b b b b, **ends** | map change (room 136 ends on it) |
| BB | 7 w if lo < 4, else none | |
| BC | b b | sub-table `01:BFCB` |
| BD | b b w (none if lo = FF) | |
| BE | lo F0, F2: w; F1: w b; else none | |
| D0 | 7 b, +4 b if (b5 & $70) in {$10, $20} | create object lo (slot lo*$18 at `$0800`) |
| D1 | lo & $80: b; else b, +b unless (b0 & 4) | move object |
| D6 / D7 | b b b / b b | |
| E0 | 00: J **ends** (jump); 01: J (call, `01:B718`); 02: 3 J **ends** (branch on menu choice `$A0` after F8FF) | |
| E1, E2, E8-EC | J | conditional jump (flag / item / random...) |
| ED | J | ; EE: lo = 0: w b J, else J |
| E4 | b | sub-table `01:D25D`, script pointer restored |
| E5 | - | call entry lo of the **common block** (top entry 11, decompressed over `$7F0000`) |
| E6 | lo x J, **ends** | random jump table |
| EF | w | runs native 65816 code at `$7F:w` (rooms 21, 24, 65 only) |
| FE | - | 00 newline; 01/02 page variants |
| FF | **ends** | 00 end; 01, 02 end + close window variants |
All other ops take no stream arguments (B9, F6, F8, F9, FA... run fixed sub-scripts through `01:B718`).
`FAxx` appears inside names in text (`FA38`, `FA4F`): FA's sub-table `01:E679` calls fixed scripts (name insert?).

## Room blocks (verified)
Table `0xD0081`: 309 room blocks (+ 14 more at top-table entries 29-42, same format). Decompressed to `$7F0000`.
Header = 9 words: e0, e1 scripts (`00:D656`, `00:D634`); e2 talk list: one pointer per NPC (count not stored:
talk index = object id - 4) to a table of up to 3 scripts (first talk / flag `$0534` / talked before, `01:A2DF`);
e3 search spots (x, y byte pairs, `FF`) + e4 one script pointer per spot (`01:C615`; A0/A1 chests are spots);
e5 spots + e6 step-trigger script pointers (`00:C2C2`, only when `$2C` != 0; not pointers in room 95);
e7 spots + e8 (flag, value) byte pairs (`01:C6BD`). Lists are laid out e3 e4 e5 e6 e7 e8 e2, then talk tables
and scripts. Common block (top entry 11, 0x1063DB): 33-word pointer table, then scripts.
`python -X utf8 tools/script_dis.py [--room N -v] [--gaps]` walks them all; quirks kept as in the original:
room 85 D008 overlap (a jump lands inside its extension), room 310 search text with no terminator.
18 text runs (100-260 bytes, after an FF02) are reached by nothing in their block (`--gaps`): dead text, or
reached from outside; check at runtime with a ROM-read probe before deciding.
Not yet walked: top entries 14-28 (other formats: 18/19 hold plain text, 20-27 tables), bank-04 script.

## Where text lives
- **Map/event scripts: LZ-compressed blocks** (see `compression.md`), decompressed to `$7F:0000`; entry words at
  `$7F0000` (`00:D656`) and `$7F0002` (`00:D634`). 158 of the 324 blocks in file `0xD0420-0x107CF3` look like script
  (~307 KB decompressed).
- **Uncompressed script in bank $04** (file `0x20000-0x27FFF`), e.g. new-game script at `$04:B930` (hard-coded
  `LDA #$B930 / STA $10` with `$12 = 4` at `01:806B`), name-entry prompt at `0x023938`. Densest text: `0x23000-0x23C00`.
- **Shop/inn/healer scripts**: top-table entries 14, 15, 18-21, 23, 28 (16, 17, 22, 24-27 alias them), LZ blocks in
  the common-block format (word table of script pointers, 0 = unused slot, then scripts). All walk clean in
  `script_dis.py` (`--top top14`), test included. 18/19 inn, 20/21 healer, 14/15/23 shops (verified by the text;
  the code that picks the entry is not yet traced: phase 4, ROM-read probe in a shop).
- Map of the bank-$04 text area (file `0x22C00-0x25800`, `tools/re_dumptext.py START END` lists it; verified by
  decoding, the pointer tables match the strings they point at):

- **Spell names**: `0x14E20F`, 28 records of 9 bytes (8-byte name in the byte encoding, then 1 byte), ファイアボール ...
  スターブラスト (`tools/re_names.py at 14E20F 9 8 28`; record layout a guess from the stride, verify with the
  FA4F handler in phase 4). Two more copies, not extracted yet (found by the phase-5 marker tour, `menu_magic` showed
  ファイアボールA): an FF-terminated name list at `0x19D3F1-0x19D4A0` (22 names, reader unknown) and the new-game
  character record at `0x1FE36` (7-byte name + rank letter `A`, then `12 50`): character records carry name copies.
- **Byte-encoded names** are capped at 8 characters by the record: English names need a wider record or a pointer
  (engine work, phase 5).
- **Credits**: `0x16245-0x16877`, script words with FF00 per line (シナリオ・ゲームデザイン, staff names).
- **Inline name codes**: `FA38` actor name, `FA39`/`FA4F` spell name, `FA3A` item name (01:FC2B: record -> 8 bytes to
  `$7E6D80`, 01:FEE3 maps them to words at `$7E6C80`, run as script), `FA3B` number, `FA47` target name.
- **Not found** (whole-ROM scan of raw bytes and every LZ block, both word and byte encodings): enemy names, menu
  command labels, save-screen labels. Probably tiles (BG3 tile words, see `0x22CA7`) or graphics: find them on screen
  with the phase-2 debug tool and `romreads_addr.lua` / a VRAM dump.
- Scanners: `tools/re_textscan.py` (glyph-word runs in raw ROM and blocks), `tools/re_names.py` (byte encoding:
  `items`, `scan`, `at OFF STRIDE LEN COUNT`), `tools/re_dumptext.py` (range listing).

## Extraction (phase 4, verified: `tests/test_extract.py` roundtrip + coverage on the original ROM)
- `python -X utf8 tools/extract.py dump [--force]` writes `script/*.json` (205 files, 2591 strings, 23 of them
  `"reached": false`); `stats`, `coverage`. Codec: `tools/textcodec.py` (`JP` word codec, `ByteCodec` for names).
  Tokens: `{nl}` FE00, `{page}` FE01, `{page2}` FE02, `{wait}` FCFF, `{actor}` FA38, `{spell}` FA39, `{item}` FA3A,
  `{num}` FA3B, `{target}` FA47, `{spell2}` FA4F; any other word inside a string is `{XXXX}` (tile words, other
  FAxx inserts such as FA03/FA3E/FA3F/FA4D, D3xx, the second code of a duplicated glyph). Space $0300 decodes as
  an ASCII space.
- A string = maximal run of walked glyph words and no-argument controls, trimmed to start and end on text (glyph,
  FE, FA, FC), split at every entry point and jump target. FFxx and every op with arguments stay outside as code.
- Files: `r<NNN>` one per room-format block (named by the lowest room id that reaches it; 309+ are top entries
  29-42), `common`, `top14/15/18/19/20/21/23/28` (shops, inns, healers), `bank04` (walked from `B04_TABLES` and
  the code immediate at 01:A286; entries carry their pointer slots in `ptrs`), `credits` (bank 02, 24 pointers),
  `items` (low table $00-$5B, key items $C0-$FF), `spells` (28).
- **Item index aliasing:** 01:8B2D reads index < $C0 at 0x24AD1, but 0x24AD1 + 20 * $5C = 0x25201, the key-item
  table: indices $5C-$BF land in the key-item records (or past them), so only $01-$5B are real low items.
- Insertion (`tools/insert.py`, called by `build.py`): `en`, else `jp`, spliced at the same address; a size change
  is refused until the block reassembler and pointer rewriting exist (phase 5).
- **Not extracted:** the 12-byte tile rows at `0x22CA7` (name-entry grid, done with the name maps); the debug flag
  viewer `0x20400-0x205FF`; the battle command label たたかう (no tile, byte or glyph copy in the ROM: graphics,
  phase 8); battle messages (`battle.md`).

## BG3 strings (phase 5, verified: marker tour `work/qa/bg3m`, 2026-11-23)
- Menu prompts and labels, yes/no, stereo/mono, status template, shop/spell description boxes: bank 04 file
  `0x20600-0x22CA6`, FF00-terminated runs of BG3 tile words (`< $0300`, one 8x8 tile each) with FAxx name inserts
  and FE00 newlines, run by the script VM (ROM-read probe: 01:B7A1 reads them in the menu scenes), so far jumps work.
- `extract.bg3_strings` -> `script/menus.json` (kind `bg3`, ids `bg3_<$04 addr>`, `tiles` = widest line in tiles
  without inserts): linear decode with byte resync, a string = a run of tile words + FA/FE words with >= 2 kana
  tiles and no glyph word (260 strings). Codecs `textcodec.bg3_jp(rom)` (tile -> kana through the byte maps
  `$04:AEAB` and `$04:B053`) and `bg3_en()` (digits/capitals `$01-$24`, `font_bg3` lowercase, space `$93`).
- Unknown tiles stay `{XXXX}` tokens: `{009F}` ends messages (likely 。), `{0096}`/`{00A3}`/`{009E}` are layout
  tiles in the magic/status templates.
- FA inserts in BG3 strings: op table `01:E679` (FA00-FA54); FA2F = FA8A (name from `$0C98` via 01:FE09), FA18 =
  FC55 (item record, `LDA #8 / JSR $FEAA` at 01:FC6B; only the op table reaches FC55), FA2B = FBC0. All print
  through 01:FEAA (BG3 tiles, cap 8 in the JP); the English hook `nm_feaa` gives FA18 9 (return $FC70) and the
  F3C0 item lists their `nm_icap` width. Lint: `batches.INSERT_TILES` + `MSG_BOX` (26-tile prompt box).
- **Battle names, battle font, battle messages**: `battle.md` (enemies and tactics extracted as `script/enemies.json`,
  `script/tactics.json`; default battle spell names become spell escapes; battle messages surveyed only).
