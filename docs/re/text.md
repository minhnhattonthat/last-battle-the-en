# Text engine, encoding, font

Dump: `rom.sha1`. LoROM, 2 MB (header `$7FC0`: "THE LASTBATTLE", map $20, type $02, size $0B, SRAM $03 = 8 KB, battery).
No earlier fan translation found (web search 2026-11-23; Giant Bomb lists none).

## Encoding (verified)
- Script = stream of **16-bit little-endian words**, read by the VM loop at `01:B79F` (`LDA [$10]; INC $10 x2`).
  Script pointer: DP `$0C00` + `$10` (24-bit, so WRAM `$7E0C10-$7E0C12`).
- Word `< $0300`: tile code, `ORA #$2000` and written straight to the BG3 tilemap buffer (`01:B7D1`). Window parts etc.
- Word `$0300-$7FFF`: glyph `code - $0300` drawn into the bitmap text box (`01:B81F` -> `01:B882`).
- Word `>= $8000`: control code; high byte looked up in the 56-byte table at `01:BAB5`, handler pointers at `01:BAED`
  (`01:BA96`). Low byte = argument. Several handlers read further words; see Control codes.
- verified by: decoding the name-entry prompt at file `0x023938` ("　この世界で使う{nl}真の名前を入力して下さい。{end}")
  word by word against the screen (`work/qa/ppu1`, frame 1150 of `tools/routes/boot.txt`), and by logging the
  glyph reads per frame (`tools/lua/romreads_addr.lua`).

## Font (verified)
- 16x16 1bpp, 32 bytes per glyph as four 8x8 1bpp tiles in order TL, TR, BL, BR. Drawn at a 12 px advance into a
  2bpp bitmap canvas on BG3 (tiles `$E0+`, map `$D800` byte addr, chr `$C000`): `01:B8F5`/`01:B8FB` jump tables
  handle the even/odd half-tile phase.
- Base pointer at `$1A:8015` = linear `$1DFCF3` -> **file 0x107CF3**; glyph address = base + (code - $0300) * 32.
- 1233 glyphs (to file 0x111713) -> codes `$0300-$07D0`. Render any range: `python -X utf8 tools/re_glyphs.py OUT.png --range 300 380 --rowfmt tltr`.
- Order: a **JIS X 0208-ordered subset** (only the characters the game uses):
  `$0300` space, `$0301-$030F` symbols (。・？！ヶ／～「『』＋－, `$030D` an odd glyph, ＊ ⇒), `$0310-$0319` ０-９,
  `$031A-$0333` Ａ-Ｚ (no lowercase seen yet), `$0334-$0383` hiragana without ゎゐゑ (を = `$0382`, ん = `$0383`),
  then katakana (not yet checked) and kanji in JIS order (界 `$0432` < 使 `$0535` < 真 `$05C2` < 世 `$05D2` < 前 `$0602` < 入 `$06B5` < 名 `$0748`).
- `tbl/jp.tbl` (generated by `tools/gen_jp_tbl.py`) holds the verified part. **Next:** identify `$0384-$07D0` by
  matching each glyph against a JIS-ordered reference font with a monotonic alignment (the order is JIS, only gaps
  are unknown), then check doubtful cells by eye on zoomed sheets with script context.
- Fixed-width 12 px cells in a 16 px glyph: English needs a VWF or a narrow font (phase 5 engine spike).

## Control codes (partly verified)
High bytes in the table: A0 A1 A3 A4 A5 B0-BE C0 C1 C2 D0-D8 E0 E1 E2 E4 E5 E6 E8 E9 EA EB EC ED EE EF F4 F5 F6 F8 F9 FA FB FC FE FF.
`tools/re_ctrl.py [-v]` lists each handler and whether it reads the script pointer.
- verified: `FE00` newline; `FF00` end of message; `FF02` end variant (seen after 。 before the next block).
- guess (static reading, confirm by full-script disassembly in phase 4): `E8xx-EBxx` conditional jumps
  (read a 16-bit in-bank target, `STA $10`, else skip it); `E6xx` jump table via `[$10],y`; `E4xx`, `E5xx` pointer
  changes (call/return?); handlers that read one extra word: B4 B5 B6 EF; several words: D6 (3), D0 (many), A0/A1
  (via `01:B718`, which pushes `$10/$12` = call), B8, BA, BC, D1, D7, E1, E2, EE, ED, EC.
  `FAxx` appears inside names in text (`FA38`, `FA4F`): likely a name/variable insert.
- The script is an event VM (text, jumps, flags, moves mixed). Extraction must follow jumps and re-assemble with
  label fixups: every jump target is a 16-bit address inside the block's WRAM image.

## Where text lives
- **Map/event scripts: LZ-compressed blocks** (see `compression.md`), decompressed to `$7F:0000`; entry words at
  `$7F0000` (`00:D656`) and `$7F0002` (`00:D634`). 158 of the 324 blocks in file `0xD0420-0x107CF3` look like script
  (~307 KB decompressed).
- **Uncompressed script in bank $04** (file `0x20000-0x27FFF`), e.g. new-game script at `$04:B930` (hard-coded
  `LDA #$B930 / STA $10` with `$12 = 4` at `01:806B`), name-entry prompt at `0x023938`. Densest text: `0x23000-0x23C00`.
- Not yet located: menu labels, item/spell/enemy names, battle messages, the name-entry kana grid (may be tile
  codes `< $0300`), save screen. Find them in phase 4 with the same `romreads_addr.lua` probe on each screen.
