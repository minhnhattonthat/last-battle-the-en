# English font for the VWF (tools/font_en.py builds build/font_en.bin + build/font_en_widths.bin for asm/vwf.asm).
# Own design, no licence encumbrance (docs/fonts.md). One block per glyph: a line "= c" (c = the character,
# "= space" for the blank), then up to 11 rows of '#' (ink) and '.' (background) drawn into cell rows TOP..TOP+10
# (font_en.py TOP; first 9 rows = cap height, last 2 = descenders). The glyph's width is its row length; the advance
# is width + 1 (one background column of spacing), except where a "w N" line after the rows sets it.
